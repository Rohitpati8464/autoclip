## 📝 How to use autoclip

You can start creating clips as soon as the app opens.

1. Open the autoclip program from your desktop.
2. Click the "Add Video" button to choose your long source video file.
3. Select your output format. You can choose vertical 9:16 for TikTok, Reels, or Shorts.
4. Choose your preferred processing mode.
   * Local mode: The app uses Whisper and Ollama to process data on your machine. This requires no internet.
   * API mode: You provide your own API key if you want to use cloud-based models.
5. Click "Start Clipping." The app tracks the speaker and adds captions automatically.
6. The app saves your finished clips in the "Exports" folder once the process ends.

## ❓ Frequently asked questions

Do I need an internet connection?
You do not need an internet connection for local processing. You only need a connection if you decide to use cloud-based API services.

Why does the app use so much power?
Video editing and AI transcriptions require high processor usage. It is normal for your computer fans to run loud while the app works.

Can I change the font of the captions?
Yes. You can adjust the font size, color, and style in the settings menu before you start the clipping process.

What if the video takes a long time?
Processing long videos requires significant computing power. Please keep your computer plugged into a power source while the app works.

## 📦 Troubleshooting

If the app fails to start, make sure you have the latest drivers for your graphics card. If you see an error during processing, clear your temporary storage folder to free up space. Restart the application if it becomes unresponsive.
